5️⃣ Configuración del temporizador
self.timer = QTimer()
self.timer.timeout.connect(self.update_frame)
self.timer.start(30)  # ~33 FPS


Explicación:

self.timer = QTimer()

Creamos un temporizador que se ejecutará periódicamente.

self.timer.timeout.connect(self.update_frame)

Conectamos la señal timeout (cada vez que el timer se dispara) a la función update_frame.

Esto significa que update_frame se llamará automáticamente cada intervalo de tiempo.

self.timer.start(30)

El temporizador se ejecuta cada 30 milisegundos, aproximadamente 33 cuadros por segundo (FPS).

Esto permite un video fluido en tiempo real.

6️⃣ Función para actualizar el frame de la cámara
def update_frame(self):
    ret, frame = self.cap.read()
    if not ret:
        return

    frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)

    h, w, ch = frame.shape
    bytes_per_line = ch * w
    qt_image = QImage(frame.data, w, h, bytes_per_line, QImage.Format.Format_RGB888)

    pixmap = QPixmap.fromImage(qt_image)
    self.label.setPixmap(pixmap)


Explicación detallada:

ret, frame = self.cap.read()

Captura un frame de la cámara.

ret → True si se pudo capturar correctamente.

frame → imagen capturada en formato BGR (como OpenCV maneja colores).

if not ret: return

Si no se pudo capturar el frame, salimos de la función para evitar errores.

frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)

Convierte la imagen de BGR (OpenCV) a RGB (PyQt).

Necesario porque PyQt y OpenCV usan diferentes formatos de color.

h, w, ch = frame.shape

Obtenemos alto, ancho y número de canales del frame.

bytes_per_line = ch * w

Número de bytes por fila, necesario para crear QImage.

qt_image = QImage(frame.data, w, h, bytes_per_line, QImage.Format.Format_RGB888)

Convertimos el frame a un QImage, que PyQt puede mostrar.

pixmap = QPixmap.fromImage(qt_image)

Convertimos QImage a QPixmap, formato optimizado para mostrar en QLabel.

self.label.setPixmap(pixmap)

Actualizamos el QLabel para que muestre el frame actual de la cámara.

7️⃣ Liberar la cámara al cerrar la app
def closeEvent(self, event):
    if self.cap.isOpened():
        self.cap.release()
    event.accept()


Explicación:

closeEvent → Método de PyQt que se ejecuta al cerrar la ventana.

if self.cap.isOpened(): self.cap.release() → Libera la cámara, evitando que quede bloqueada para otros programas.

event.accept() → Permite que la ventana se cierre normalmente.

✅ Resumen general

Este código crea una ventana de PyQt6 que muestra video en tiempo real de la cámara del portátil.

Utiliza OpenCV para capturar frames y PyQt6 para mostrarlos en un QLabel.

Un QTimer refresca la imagen constantemente (~33 FPS).

La cámara se libera automáticamente al cerrar la ventana.

Todo está organizado en una clase CameraApp, lo que permite expandirla fácilmente con botones, grabación, filtros, etc.
